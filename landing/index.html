Your coding agent asks.

When your coding agent needs your call (a stack, a review, an API key), it sends you a link instead of waiting at the terminal. You answer from your phone. It reads your answers as JSON and gets back to work.

Why not just ask in the terminal?

Your agent can already ask you questions. Here's what changes when it sends a form instead.

In the terminalWith ask-form
Where you answerAt the keyboard. Step away and the agent waits.Any browser, phone included. The agent keeps working meanwhile.
How many questionsA few at a time, turn after turn.Twenty at once, in pages, with its picks pre-selected.
What you seeText.Mockups, diagrams, tables and code.
What it gets back“1b, yes, the second one”, to interpret.JSON, keyed by question.
SecretsPasted into the chat and kept in the transcript.Written straight to .env. The model never sees them.

Manual install

Linux and macOS, x86-64 or arm64. One command installs the binary in ~/.local/bin, connects your machine to this relay, starts the background service and adds the Claude Code skill.

curl -fsSL {{ORIGIN}}/install.sh | sh
  • Without the relay (forms answerable on this machine only): curl -fsSL {{ORIGIN}}/install.sh | sh -s -- --local
  • With Go 1.22+: go install github.com/GabrielVidal1/ask-form/cmd/ask-form@latest, then ask-form setup
  • Or take a binary from GitHub Releases, then run ask-form setup

The service installs new releases by itself (ASK_FORM_AUTO_UPGRADE=notify or off stops that). ask-form upgrade updates by hand; ask-form uninstall removes the service and the skill. Other agents than Claude Code: ask-form skill print --body >> AGENTS.md.

What the agent runs 
# create: returns at once with the link to show you
ask-form create --title "Project setup" --fields-file spec.json
{"id":"project-setup_k3f9q2","status":"pending","url":"{{ORIGIN}}/f/project-setup_k3f9q2?token=…",…}

# then wait in the background: exit 0 = answered, 3 = closed unanswered, 4 = timed out
ask-form wait project-setup_k3f9q2 --timeout 30m
{"id":"project-setup_k3f9q2","status":"submitted","answers":{"stack":"Vite + React","deploy":true},…}

Field types: text, textarea, number, slider, date, select, radio, multiselect, checkbox, secret, picture and mockup choices, markdown and HTML blocks, and “Other…” on every choice. The full reference is the skill.

Private by design

  • Forms stay on your machineThe relay only passes page requests through. It stores no form and no answer.
  • One private link per formA 256-bit token, answered once, then closed. Every form expires (24 h by default).
  • Secrets go to .envA secret field's value never appears in the answers the agent reads.
Where things live

Same 404 for an unknown form and a wrong token, no referrer, no cache, no indexing, a strict CSP, mockups in sandboxed script-free frames. More in how it works.
