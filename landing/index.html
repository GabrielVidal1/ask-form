ask-form

Your coding agent asks.
You answer from anywhere.

A tiny Go tool that lets Claude (or any CLI agent) ask you structured questions through a private web form. Claude gets a link, you answer from your phone, and the answers come back as JSON.

Get it

Use now

Paste this into Claude Code, or any coding agent running on your computer, then finish the sentence with what you want to be asked. Not the Claude chat app: its sandbox can't keep ask-form running. The agent reads /agent-install, installs ask-form, sets itself up to use it and sends you that first form.

Fetch {{ORIGIN}}/agent-install and follow it to install the ask-form skill and set it up, then ask me with it: what you want to be asked
Manual install

Linux and macOS, x86-64 or arm64. One command installs the binary in ~/.local/bin, connects your machine to this relay, starts the background service and adds the Claude Code skill.

curl -fsSL {{ORIGIN}}/install.sh | sh
  • Without the relay (forms answerable on this machine only): curl -fsSL {{ORIGIN}}/install.sh | sh -s -- --local
  • With Go 1.22+: go install github.com/GabrielVidal1/ask-form/cmd/ask-form@latest, then ask-form setup
  • Or take a binary from GitHub Releases, then run ask-form setup

The service installs new releases by itself (ASK_FORM_AUTO_UPGRADE=notify or off stops that). ask-form upgrade updates by hand; ask-form uninstall removes the service and the skill. Other agents than Claude Code: ask-form skill print --body >> AGENTS.md.

How it works

1Claude creates a formask-form create takes a JSON field spec and prints a one-time private link.
2You answer itThe form opens in any browser: one theme per page, picture choices, mockups. It works without JavaScript.
3Claude reads the answersask-form wait returns the answers as one JSON object, keyed by question.

Where things live

Built to be boring and safe

  • Unguessable linksA 256-bit token per form. Only its SHA-256 is stored, and it's compared in constant time.
  • One answer, then closedThe first submission closes the form. Every form expires (24 h by default).
  • Nothing leaksAn unknown form and a wrong token get the same 404. No referrer, no cache, no indexing.
  • Strict pagesNo third-party assets and a strict CSP. Mockups run in sandboxed, script-free frames.
  • Secrets stay secretA password field never appears in the answers the agent reads. It's written straight into a .env file instead.
  • Plain filesEach form is one immutable JSON file plus a JSONL of its response. There's no database.

For the agent

# create: returns at once with the link to show the user
ask-form create --title "Project setup" --fields-file spec.json
{"id":"project-setup_k3f9q2","status":"pending","url":"{{ORIGIN}}/f/project-setup_k3f9q2?token=…",…}

# then wait in the background: exit 0 = answered, 3 = closed unanswered, 4 = timed out
ask-form wait project-setup_k3f9q2 --timeout 30m
{"id":"project-setup_k3f9q2","status":"submitted","answers":{"stack":"Vite + React","deploy":true},…}
